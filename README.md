# ⚡ FlowTask

A premium dark-themed React productivity app built with Vite.

🔗 **Live Demo:** https://suneerkhan.github.io/FlowTask/

## Features

- ➕ Add, edit, and delete tasks
- ✅ Mark tasks as completed with sparkle animation
- 🔴 Priority system — High, Medium, Low
- 📅 Due date with overdue warning
- 🔍 Search tasks instantly
- 📊 Live progress bar with percentage
- 💾 Local storage — tasks saved permanently
- 🎉 Confetti when all tasks are completed
- 💡 Daily motivational quote
- 🎨 Premium Midnight dark theme with dot grid background

## Tech Stack

- React 18
- Vite
- CSS-in-JS (inline styles)
- localStorage API
- Canvas API (confetti + sparkle effects)

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx gh-pages -d dist -b gh-pages
```
